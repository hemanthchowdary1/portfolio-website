Full Stack Engineer

Category

Overview

Incursion Tracker is a specialized full-stack application built for Marvel Cinematic Universe fans to systematically log their watch history leading up to Avengers: Doomsday. Beyond its niche, the project bridges the gap between aesthetic frontend design and complex backend infrastructure. It features a highly focused, thematic React UI that is securely powered by a robust Django and PostgreSQL architecture.

The Network Challenge

While deploying the authentication system to production, standard cloud firewall configurations actively blocked the outbound SMTP ports necessary for secure email delivery, threatening the core OTP verification flow.

The Engineering Solution

Instead of compromising the feature or moving to a less secure cloud provider, I refactored the backend email architecture to utilize a custom HTTP API integration via Brevo. This bypassed the server-level port restrictions entirely, resulting in an instant, highly secure OTP delivery system communicating exclusively over HTTPS.
